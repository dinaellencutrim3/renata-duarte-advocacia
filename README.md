# Renata Duarte Advocacia — Landing Page

Landing page para escritório de advocacia boutique, com layout editorial (hero dividido, áreas de atuação em lista numerada, números em destaque) e paleta preto + verde esmeralda.

🔗 Link: https://dinaellencutrim3.github.io/renata-duarte-advocacia/

## Estrutura
- `index.html` — estrutura da página
- `style.css` — estilos (paleta, tipografia, layout responsivo)
- `script.js` — interatividade (menu mobile, scroll reveal, contadores animados, carrossel de depoimentos, formulário de contato via WhatsApp)

## Como rodar localmente
Abra o `index.html` direto no navegador, ou sirva a pasta com qualquer servidor estático (ex: extensão "Live Server" do VSCode).

## Deploy
Publicado via GitHub Pages a partir da branch `main`.

## Personalização pendente
- Trocar o número de WhatsApp de exemplo em `script.js` (`WHATSAPP_NUMBER`) e no `index.html`
- Substituir a foto placeholder pela foto real
- Conferir dados de contato (endereço, e-mail, OAB)
